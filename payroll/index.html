How to Use This Payroll Tool

Follow these steps to process payroll for your organization

Getting started
1
Set up your Organization Go to the Organization tab. Fill in your company name, address, and registration details (PF, ESI, GSTIN). Configure which statutory deductions apply — PF, ESIC, and/or Professional Tax. Set your state's PT slab. Add your salary breakup components (Basic, HRA, etc.) so payslips show a proper earnings breakdown. Click Save Organization.
2
Add Employees Go to the Employees tab. Click Add Employee and fill in their ID, name, designation, department, date of joining, date of birth, and gross pay. Each employee belongs to the currently selected organization. You can edit or remove employees at any time using the Edit button next to each row.
3
Run Payroll Go to Run Payroll. Select the month and year. Enter the number of Present Days for each employee. Overtime days are automatically added on top. Click Calculate Payroll to compute earnings, statutory deductions (PF, ESIC, PT), and net pay.
4
View & Print Payslips After calculation, click View Payslip next to any employee to see their individual payslip. Use Print Payslip to print or save as PDF. Use Bulk Download Payslips to print all payslips in one go — each employee gets a separate page.
5
Multiple Organizations Use the organization switcher at the top to switch between organizations. Each organization has its own employee list, deduction settings, and salary breakup. Click New Org to create an additional organization (e.g. a sister company in the same business group).
6
Export & Import Data In the Employees tab, use Export List to save your employee data as a JSON file. Use Import List to load a previously exported file. Payroll results can be exported as CSV for use in Excel or accounting software.
Statutory deduction rules
PF (Provident Fund)
Employee contribution: 12% of Basic salary
Capped at ₹1,800/month (when Basic > ₹15,000)
Basic salary = as per your breakup %
ESIC
Applicable only if gross earned ≤ ₹21,000/month
Employee: 0.75% of gross earned
Not applicable for annual-pay employees above threshold
Professional Tax
Varies by state. Configure your state's slab in Organization settings.
Applied on gross earned per month.
